Inspecter MadaFlow avec PowerShell

Un guide A à Z pour explorer l'architecture, lire les fichiers, retrouver les composants Next.js, examiner l'API Django, vérifier Docker et PostgreSQL, contrôler Git et générer un rapport d'inspection — sans modifier accidentellement ton code.

Prudence
Ce guide privilégie les commandes de lecture. Évite de publier les fichiers `.env`, secrets JWT, clés API, mots de passe et données personnelles dans un rapport partagé.
01 · Démarrage

Comprendre les commandes de base

PowerShell est le terminal Windows utilisé dans VS Code. Les commandes ci-dessous servent principalement à se déplacer et à observer les fichiers.

Afficher le dossier actuel

Indique le chemin dans lequel les prochaines commandes seront exécutées.

Get-Location

Lister fichiers et dossiers

Affiche le contenu du répertoire courant. `ls` et `dir` sont des alias courants.

Get-ChildItem

Changer de dossier

Permet d'entrer dans un dossier ou de revenir au parent avec `..`.

Set-Location .\\frontend

Nettoyer le terminal

Efface l'affichage du terminal sans supprimer les fichiers.

Clear-Host

Variantes utiles de Get-ChildItem

Get-ChildItem -ForceInclut les éléments cachés, par exemple `.git` et `.env` (ne partage pas leur contenu).
Get-ChildItem -DirectoryAffiche uniquement les dossiers.
Get-ChildItem -FileAffiche uniquement les fichiers.
Get-ChildItem -RecurseExplore les sous-dossiers récursivement.
Get-Content README.mdLit le contenu d'un fichier texte.
Select-String -Pattern "TODO"Recherche un texte dans le contenu de fichiers.
tree /A /FAffiche l'arborescence en caractères ASCII, avec les fichiers.
02 · Architecture

Accéder à MadaFlow et examiner sa structure

Place-toi à la racine du projet. Adapte le chemin si ton dossier a changé.

PowerShell — chemin du projet
Set-Location "D:\Document Adelin\Projet Deployer\madaflow (dium)\Teste\madaflow backend\madaflow"
Get-Location

Confirmer le chemin.

Get-ChildItem -Force

Voir les fichiers racine, y compris cachés.

tree /A /F

Voir l'arborescence complète.

Lister les dossiers principaux

Get-ChildItem -Directory

Enregistrer l'arborescence

Génère un fichier texte consultable dans VS Code.

tree /A /F > structure-projet.txt
Attention : une exploration récursive complète peut être très volumineuse. Évite de parcourir `node_modules`, `.next`, `.git`, `venv`, `__pycache__` et les dossiers de build si tu veux un rapport lisible.

03 · Frontend

Inspecter Next.js, React et TypeScript

Les exemples supposent une structure `frontend/src`. Si ton projet utilise `app/` directement à la racine du frontend, adapte simplement le chemin.

Entrer dans le frontend

Set-Location .\\frontend
Get-ChildItem

Voir la racine frontend.

Get-ChildItem .\\src

Voir le dossier source.

Get-ChildItem .\\src\\app

Voir les routes App Router.

Get-Content .\\package.json

Lire scripts et dépendances.

Trouver les composants React

Recherche les fichiers TSX et JSX dans `src`.

Get-ChildItem .\\src -Recurse -File -Include *.tsx,*.jsx

Trouver les fichiers TypeScript

Get-ChildItem .\\src -Recurse -File -Include *.ts,*.tsx

Trouver les feuilles de style

Get-ChildItem .\\src -Recurse -File -Include *.css

Examiner la config TypeScript

Get-Content .\\tsconfig.json

Trouver les fichiers de config Next

Get-ChildItem -File -Filter "next.config.*"

Lister toutes les pages

Get-ChildItem .\\src\\app -Recurse -File -Include page.tsx,page.jsx

Explorer les pages, composants et appels API

Lister les layouts

Lister tous les composants

Get-ChildItem .\\src\\components -Recurse -File

Rechercher une fonctionnalité

Exemple : retrouver le texte « Signalements » dans les fichiers source.

Get-ChildItem .\\src -Recurse -File -Include *.tsx,*.ts | Select-String -Pattern "Signalements"

Lister les fichiers API

Get-ChildItem .\\src\\lib\\api -Recurse -File

Lire le module des signalements

Get-Content .\\src\\lib\\api\\reports.ts

Rechercher les appels HTTP

Get-ChildItem .\\src -Recurse -File -Include *.ts,*.tsx | Select-String -Pattern "fetch\\(|axios|baseURL"

06 · Backend

Inspecter Django et son API REST

Entrer dans le backend

Set-Location ..\\backend
Get-ChildItem -Directory

Dossiers backend.

Get-ChildItem -Recurse -File -Filter *.py

Fichiers Python.

Get-ChildItem .\\config

Configuration Django si le dossier existe.

Get-ChildItem .\\apps -Directory

Applications si elles sont sous `apps`.

Repérer les fichiers Django

ÉlémentCommande
ModèlesGet-ChildItem .\\apps -Recurse -Filter models.py
VuesGet-ChildItem .\\apps -Recurse -Filter views.py
SérialiseursGet-ChildItem .\\apps -Recurse -Filter serializers.py
RoutesGet-ChildItem .\\apps -Recurse -Filter urls.py
PermissionsGet-ChildItem .\\apps -Recurse -Filter permissions.py
TestsGet-ChildItem .\\apps -Recurse -Filter test*.py
Get-Content .\\config\\settings\\dev.py

Le chemin exact des paramètres dépend de ton architecture Django. Vérifie d'abord les dossiers présents.

Vérifier PostgreSQL

Lister les tables.

\\d nom_table

09 · Automatisation

Générer un rapport d'inspection

Ce script crée un fichier `rapport-inspection.txt` à la racine. Il collecte les structures et les configurations non secrètes, sans lire les fichiers `.env`.

Avant de lancer : ouvre PowerShell à la racine du dépôt MadaFlow. Le script est conçu pour lire les informations et écrire uniquement le rapport de sortie.
rapport-inspection.ps1
Script PowerShell — version prudente
# MadaFlow - Rapport d’inspection (lecture seule)
$ErrorActionPreference = "Continue"
$rapport = Join-Path (Get-Location) "rapport-inspection.txt"

"RAPPORT D’INSPECTION MADAFLOW" | Out-File $rapport -Encoding utf8
"Date : $(Get-Date -Format "yyyy-MM-dd HH:mm:ss")" | Out-File $rapport -Append -Encoding utf8
"Racine : $((Get-Location).Path)" | Out-File $rapport -Append -Encoding utf8

function Add-Section($titre) {
  "`r`n===== $titre =====" | Out-File $rapport -Append -Encoding utf8
}

Add-Section "DOSSIERS ET FICHIERS A LA RACINE"
Get-ChildItem -Force -ErrorAction SilentlyContinue |
  Where-Object { $_.Name -notin @("node_modules", ".next", ".git", "venv", ".venv", "__pycache__") } |
  Select-Object Mode, Name |
  Format-Table -AutoSize | Out-String |
  Out-File $rapport -Append -Encoding utf8

Add-Section "STRUCTURE FRONTEND"
if (Test-Path ".\frontend\src") {
  Get-ChildItem ".\frontend\src" -Directory -Recurse -ErrorAction SilentlyContinue |
    Where-Object { $_.FullName -notmatch "\\(node_modules|\.next|\.git|__pycache__)\\?" } |
    Select-Object -ExpandProperty FullName |
    Out-File $rapport -Append -Encoding utf8
} else { "Dossier frontend/src non trouvé." | Out-File $rapport -Append -Encoding utf8 }

Add-Section "FICHIERS SOURCE FRONTEND"
if (Test-Path ".\frontend\src") {
  Get-ChildItem ".\frontend\src" -Recurse -File -Include *.tsx,*.ts,*.jsx,*.js,*.css -ErrorAction SilentlyContinue |
    Where-Object { $_.FullName -notmatch "\\(node_modules|\.next|\.git)\\?" } |
    Select-Object -ExpandProperty FullName |
    Out-File $rapport -Append -Encoding utf8
}

Add-Section "PACKAGE.JSON"
if (Test-Path ".\frontend\package.json") {
  Get-Content ".\frontend\package.json" | Out-File $rapport -Append -Encoding utf8
}

Add-Section "STRUCTURE BACKEND"
if (Test-Path ".\backend") {
  Get-ChildItem ".\backend" -Directory -Recurse -ErrorAction SilentlyContinue |
    Where-Object { $_.FullName -notmatch "\\(venv|\.venv|__pycache__|\.git)\\?" } |
    Select-Object -ExpandProperty FullName |
    Out-File $rapport -Append -Encoding utf8
}

Add-Section "FICHIERS DOCKER COMPOSE"
$composeFiles = @("compose.yaml", "compose.yml", "docker-compose.yml", "docker-compose.yaml")
foreach ($f in $composeFiles) {
  if (Test-Path $f) {
    "Fichier : $f" | Out-File $rapport -Append -Encoding utf8
    Get-Content $f | Out-File $rapport -Append -Encoding utf8
  }
}

Add-Section "ETAT GIT"
git status --short 2>&1 | Out-File $rapport -Append -Encoding utf8
git log -5 --oneline 2>&1 | Out-File $rapport -Append -Encoding utf8

Add-Section "ETAT DOCKER"
docker compose ps 2>&1 | Out-File $rapport -Append -Encoding utf8

Add-Section "FIN DU RAPPORT"
"Rapport créé : $rapport" | Out-File $rapport -Append -Encoding utf8
Write-Host "Rapport créé : $rapport" -ForegroundColor Green
1. Enregistrer le script

Colle le script dans un fichier nommé `rapport-inspection.ps1` à la racine.

2. L'exécuter

Dans PowerShell : .\rapport-inspection.ps1

Contrôle avant partage : le rapport peut contenir des noms de fichiers, chemins locaux, noms de services et paramètres de configuration. Relis-le et masque toute information confidentielle avant de l'envoyer.
